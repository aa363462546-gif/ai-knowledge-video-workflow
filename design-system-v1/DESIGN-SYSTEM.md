# 视觉设计系统 · 第一版

本版把参考图中的暖白、近黑、陶红与柔和粉蓝米色，整理成可复用的静态视觉语言。适用于财经、科技、商业与知识讲解：中文标题有分量，信息主次清楚，说明少而必要，细线建立边界，柔和卡片承载内容。

本文件描述当前 `index.html`、`tokens.css` 与 `preview.css` 的实际实现。整体视觉风格已获用户认可；下文保留首版参数的来源与候选说明。2026-10-19 整合时，本目录从聊天镜像安全复制至本地项目，作为新创作的统一视觉入口；原变量、字体、预览与历史样片均保留。动画继续使用现有 GSAP，设计系统不建立动画引擎。

## 1. 使用边界

- 固定的是字体气质、配色角色、边界、形状与轻微层次；每次构图应从实际内容出发。
- 大标题负责表达结论，正文负责解释，图表和关系图负责展示证据、步骤与关系。装饰不能取代信息。
- 卡片、胶囊、柱状图、圆形流程是可选表达手段，不要求每页使用，也不要求照搬预览的数量与位置。
- 建筑摄影不属于本系统的必需元素。内容确实需要照片、界面、案例截图或实物时，可以采用，并保留本系统的文字与边界语言。
- 预览中的业务数据、方案表现与年份数列均为虚构，只演示视觉表达。

## 2. 字体与字形

| 内容 | 当前字体 | 实际用法 |
| --- | --- | --- |
| 中文 | Source Han Sans SC（思源黑体，简体中文默认字形） | 中文正文、标题、节点与说明 |
| 英文与数字 | Inter | 拉丁字母、数字、金额、百分比；混排时优先命中 |
| 后备字体 | Noto Sans CJK SC、PingFang SC、Microsoft YaHei、sans-serif | 对本地字体未覆盖字符或加载失败提供后备 |

`--font-text` 的顺序是 Inter、思源黑体及系统后备。Inter 不含中文字形，中文按字形回退到思源黑体。`--font-cn` 与 `--font-latin` 用于需要明确指定字形来源的部位。页面已设置 `lang="zh-CN"`，并关闭浏览器合成字重、合成斜体。

两套字体均随目录提供 WOFF2 可变字体：思源黑体声明字重 250–900，Inter 声明 100–900。当前预览使用 `font-display: block`。字体授权说明中的 `swap` 代码是独立使用参考，不能据此判断当前预览的加载策略。当前文件没有原生斜体。

预览以 400 为正文、500/600 为中间层级、700 为标题、800 为粗中文大标题；部分组件直接使用可变字重 650 或 750。关键数值、对比值使用 `tabular-nums`，保持数字列对齐。字体来源、完整授权与文件覆盖核对见 [FONT-LICENSES.md](FONT-LICENSES.md)。

## 3. 颜色角色

### 已采纳的七个参考主色

| 变量 | 色值 | 角色与使用 |
| --- | --- | --- |
| `--color-paper` | `#F7F6F2` | 暖白主背景，提供大面积安静底色 |
| `--color-ink` | `#171717` | 近黑主体文字、标题与关键标注 |
| `--color-accent` | `#C44D36` | 陶红，突出当前讲述的重点、结论或核心节点 |
| `--color-gray` | `#9CA3AF` | 中性灰，对照数据与非重点图形 |
| `--color-beige` | `#E8E1D9` | 米色，中性分组、步骤与柔和底色 |
| `--color-pink` | `#FAD9D4` | 浅粉，步骤、分类或需要关注的信息 |
| `--color-blue` | `#A7C7E7` | 浅蓝，分类、输入与信息状态 |

暖白与近黑建立主要阅读关系，陶红集中在当前焦点。粉、蓝、米色承担信息区分；浅色底上的文字采用近黑。中性灰不承担正文。颜色意义应在同一作品中保持一致，并用文字、数值或形状补足含义。

### 首版衍生颜色候选

| 变量 | 色值 | 当前实现 |
| --- | --- | --- |
| `--color-surface` | `#F0EEEA` | 浅中性内层底、步骤条、普通卡片标题与行动胶囊 |
| `--color-secondary` | `#514E49` | 次要文字、流程连接线、深色章节胶囊 |
| `--color-line` | `#D8D5CF` | 外边界、分隔线、图表网格 |
| `--color-rule` | `#AAA79F` | 胶囊旁的细横线、VS 圆边界 |
| `--color-accent-text` | `#A63825` | 小字号深陶红重点、增长数字、链接悬停 |
| `--color-on-accent` | `#FFFFFF` | 陶红或深色底上的反白文字 |

这组颜色用于补足文字与线条角色，属于待用户确认的候选值。当前柱状图另有 `#858D99` 灰色描边，其他轻微边界使用近黑透明色；这些是预览中的局部处理，并未另立一套色板。

### 状态与交互

| 状态 | 当前底色 | 同时提供的线索 |
| --- | --- | --- |
| 待开始 | surface | 明确状态文字 |
| 进行中 | 浅蓝 | 明确状态文字 |
| 需关注 | 浅粉 | 明确状态文字 |
| 已完成 | 米色 | 状态文字与勾选图标 |

状态文字均为近黑。这些是静态状态示意；本版没有执行状态切换的交互逻辑。陶红表示讲述焦点，不预设上涨、下跌、危险或完成含义。链接悬停使用深陶红，键盘聚焦使用 2px 陶红轮廓、5px 外偏移；文本选择使用浅粉底与近黑字。

## 4. 字号与阅读层级

下表是当前桌面浏览预览的参考值，单位为 CSS px。

| 角色 | 当前字号 / 字重 | 行高与用途 |
| --- | --- | --- |
| 封面大标题 | 72 / 800 | 1.16；建立入口与主要结论 |
| 主标题字样 | 44 / 800 | 1.25；字体层级示例 |
| 次级标题字样 | 28 / 700 | 1.35；组织结构 |
| 正文 | 20 / 400 | 1.6；完整说明 |
| 辅助说明 | 16 / 400 | 继承正文行高；补充必要语境 |
| 面板主标题 | 34 / 800 | 1.3；独立信息组的阅读起点 |
| 关键数字 | 76 / 650 | 1.05；数字与单位分级，单位 24px |
| 变化百分比 | 36 / 650 | 1.2；以深陶红强调变化 |

标题主要使用 `-0.025em` 字距，英文与大数字主要使用 `-0.035em`。实际组件还有 14–23px 的标签、说明与节点文字，未强行收敛为同一个字号。

预览包含 1199px、900px、620px 三组窄屏调整；部分列会堆叠，说明移到标题下方，图表 SVG 的标注字号在窄屏时增大。封面标题在这些区间分别调整为 64px、54px、50px；窄屏字样主标题为 28px，正文为 18px。流程与关系图在手机上使用同内容的窄幅 SVG 排法，保留方向和颜色语义，避免将桌面整图直接缩成小字。具体覆盖以 `preview.css` 为准。

这些数值不直接等于视频字号。用于视频时，应按实际画幅、观看设备、观看距离、停留时间与当前内容重新决定大小和分行；不通过缩小字体把过多内容塞进画面。内容超过可清楚阅读的容量时，优先调整分组、构图、展示顺序或分页。

**重要信息必须清晰可读，没有必要展示的信息直接不显示。** 必要名称、数字、单位、条件和关系标注应准确保留、靠近对应对象，并在预计播放大小下能够辨认；不同角色不必采用同一字号。辅助文字先判断是否必要，再决定层级，不能把浏览规范中的 14–20px 说明直接当作视频标注尺度。

主画面无需逐字复述 SRT，也不靠灰色小字、重复标签或说明段落填补留白。非讲解主题的技术解释、制作备注和内部状态留在创作文件，不展示给观众。必要的次要文字使用系统已有的可读文字色；减少无效文字比把整组说明缩小更合适。

## 5. 网格、对齐与留白

预览主内容最大宽度为 1360px，桌面两侧各预留至少 48px；中等宽度改为 32px，手机改为 20px。区域标题、面板边界与主要内容共享外侧对齐线。

设计变量提供 12 列、24px 栏沟的候选网格；当前页面没有把所有区域锁定成一个 12 列模板。封面采用 1.25:1 的非对称双栏；基础语言与质感区使用双栏、64px 间隔；组件区使用双栏、24px 间隔；图表与指标使用 2:1。页面底部的 12 列色块仅示意共享网格，该示意的栏沟实际是 8px。

候选间距刻度为 4、8、12、16、24、32、48、64、96px。当前实现也按内容使用 10、18、20、22、28、30、40、72px 等局部值。常规区块间距为 64px，手机为 40px；面板内边距桌面约 28–30px，手机约 20–24px。

构图时先决定一个明确阅读起点，再建立标题、图形、标签与说明的对齐关系。组内较紧，组间较松；少量内容可以留白，复杂关系可以获得更大面积。允许不对称、跨列、错位与局部聚合，前提是读者能辨认信息顺序。不要把“共享网格”理解为每页均分成相同卡片。

## 6. 边界、卡片与胶囊

| 元素 | 当前候选尺寸 | 表达作用 |
| --- | --- | --- |
| 外层面板 | 1px 细线、8px 圆角 | 安静划分独立信息组 |
| 对比卡片 | 16px 圆角 | 承载对应维度；重点一方用陶红边界与标题条 |
| 分类胶囊 | 999px 圆角 | 短标签、状态与章节类别 |
| 编号步骤 | 桌面 58px 圆形编号、长胶囊底 | 区分编号、动作标题与一句说明 |
| 流程连接线 | 1.5px | 通过方向和箭头说明关系 |

面板外框保持小圆角，内部卡片、节点与胶囊更柔和。不能只靠增加圆角建立层级；标题、空间与边界仍承担主要组织作用。

当前步骤示例为三步，圆形循环为四步，对比示例为两方。它们演示视觉语言，并非内容槽位限制。实际内容可以增加、减少、改为纵向或拆开；不为凑齐数量新增空泛步骤。

## 7. 图表与关键数字

当前预览使用内联 SVG，图表坐标系为 `800 × 360`，没有图表库依赖。示例包括柱状图、同一数列的趋势线、直标数值、图例与独立关键数字。

- 柱状图纵轴从 0 开始，当前范围为 0–100、刻度间隔 25；标明年份与单位。
- 往年数值使用中性灰，当前焦点使用陶红。网格使用 line，标签使用近黑或 secondary。
- 折线与柱形使用同一数列、同一纵轴。图例已说明“同一数列趋势”，避免被理解为另一项指标。
- 关键数字配套显示年份、单位、相对基准与绝对增量，不让百分比脱离语境。
- 图表文本与 SVG 的 `title`、`desc` 都要随实际数据更新；不能只换可见数字。

本页虚构数列为 2021–2024 年的 12、28、52、86，单位为万。2024 年相对 2023 年增加 34 万，增长率为 `(86 - 52) ÷ 52 × 100% = 65.3846…%`，保留一位小数为 `+65.4%`。这说明计算关系，不构成真实业务结论。

增加新图表时，先选择能够表达当前问题的图形，再沿用颜色、文字、细线与重点规则。`--chart-series-2` 和 `--chart-series-3` 已提供浅蓝、米色候选变量，当前图表尚未展示独立多序列效果。

## 8. 流程与信息关系

当前两个示例使用内联 SVG，坐标系均为 `600 × 440`。

圆形流程用四个节点表达“观察问题 → 分析原因 → 制定方案 → 执行验证 → 观察问题”。编号、位置与箭头共同表达顺序；中央文字说明循环目的。

信息关系用三类输入汇入核心判断，再输出行动方案。事实数据、实际情境与已有经验有独立节点，核心判断使用更大的陶红节点，输出使用浅中性胶囊。箭头表达实际输入、输出关系。

实际使用时，先核对连接方向、节点含义和节点之间的真实关系，再安排位置。流程可以横向、纵向、循环或分支；信息汇聚可以采用非对称结构。只有确实存在反馈的过程才画循环，只有确实存在方向的关系才加箭头。节点文字应短而明确，解释可以放在节点旁，不通过挤满节点说明复杂关系。

## 9. 材料与轻微层次

本版材料以纯色为底，柔和色块与清晰几何辅助区分。预览中的微弱质感来自 12% 白色线性渐变、6% 近黑内描边，以及 `0 7px 18px rgb(23 23 23 / 7%)` 软阴影。部分标题条与胶囊使用微弱顶部内高光。

这些处理只在编号、章节胶囊与材料示例等局部出现，不给每个元素都加阴影。当前页面没有照片、噪点纹理、外部图片背景或三维模型。纯色、圆、矩形、三角形即可表达本版材料语言；内容需要真实材料时再加入相应资产。

### 与项目 Skill 和自由 SVG 配合

[项目 Skill](../skill-drafts/ai-visual-motion/SKILL.md) 负责内容理解、表达选择、构图、SVG/HTML/CSS、动画和视觉检查；本目录是字体、颜色与质感的统一来源。新页面用相对路径直接链接本目录 `tokens.css`，字体 URL 继续相对该 CSS 解析，不复制一套 `@font-face` 或色板。只读设计规范即可设计，无需先启动预览服务器。

例如位于项目 `tests/某次验证/index.html` 的页面可这样引用；换目录时按实际位置调整 `href`：

```html
<link rel="stylesheet" href="../../design-system-v1/tokens.css">
<style>
  body { background: var(--color-paper); color: var(--color-ink); font-family: var(--font-text); font-synthesis: none; }
  svg .subject { fill: var(--color-beige); stroke: var(--color-rule); stroke-width: var(--stroke-diagram); }
  svg .focus { fill: var(--color-accent); }
  svg text { fill: var(--color-ink); font-family: var(--font-text); }
</style>
```

SVG 的形状、坐标、分组与各状态布局由当前内容决定；轻高光、细边界与局部软阴影按 §9 使用。`preview.css` 包含展示页排版，不必整份引入；卡片、流程和现有图形都不是创作槽位。完整目录包含本地字体，可直接用文件路径打开，无需 CDN 或构建；截图或定位前等待 `document.fonts.ready`。

动画按 [现有动态与时间指导](../skill-drafts/ai-visual-motion/references/motion-and-time.md) 使用本地 GSAP 与暂停时间轴。先以真实内容确定可读状态，再通过同一批对象的移动、重组与焦点交接连接状态；设计变量不接管时间轴或限制新动作。
