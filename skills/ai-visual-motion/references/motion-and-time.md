# 动态导演、场景空间与时间定位

正式口播创作在设计、编码前读取。本文件补充主 Skill §3–4 的构图、导演与空间实现方法，沿用 HTML/CSS/SVG 与现有 GSAP 暂停时间轴，不为此接入新引擎或增加规划文件。

## 随口播组织主体与焦点

- 按当前知识点选择主体与配角，用位置、尺度、层级及动作分配注意力。原主体可以缩小、移开并退为背景，次要对象也可以放大接管焦点；不把所有对象始终放在同等级强调上。
- 有因果关系、需要持续辨认的对象保持视觉身份和必要的空间联系，通过同一对象的状态变化、移动、聚合或重组承接讲解。数量流动可让同一批对象呈现去向与剩余，再由数字或图表接续；不制造原文没有的因果。
- 场景环境与延续主体分层：旧环境退出、新环境进入时，主体可继续移动或改变尺度来完成交接。知识点结束后，失去解释作用的对象正常退出；需要时可按语义返回，不强制永久留屏或一镜到底。
- 镜头从当前焦点自然带向下一焦点：整体与局部可推拉，流程可沿空间关系推进，重新比较可重排，无关话题可直切。金句、图表、具象动作、数字和空间画面按内容灵活组合，不将某次实验的物体、窗口、胶片、坐标或转场顺序做成模板。

## 文字强调与语义重音

阅读完整文案与 SRT 时，自主识别核心结论、认知反转、关键数字、重要因果关系和有力量的收尾金句，按理解需要选择强调：重点内容突出，普通解释自然过渡，不强制每句话都强调。

- 可按语义使用局部文字放大、重点词变色、关键词与辅助文字的大小对比、动态排版、适当的独立结论镜头，以及与语音重音同步的短促强调动作；不固定效果、频率或镜头数量。
- 主视觉提炼必要的关键词、短结论或数字关系，不重复显示已有的完整字幕，不把整个视频变成大字字幕。保持原意与必要条件，不为追求冲击力改变结论。
- 强调跟随实际口播与已有 SRT 的语义时点，不提前展示尚未说出的结论；短促动作完成后留出稳定阅读时间。
- 文字与当前视觉主体协调：可以辅助标注图形，也可在适合时接管焦点；重要图形仍承担解释作用时，不让文字与它争抢注意力。延续正式 V2.1 的字体、颜色角色和材料语言。
- 将文字放大后的尺寸及完整运动范围计入当前构图，不遮挡已有图形、字幕或其他重要信息。需要让位时重排或分时展示，过时的强调文字随状态交接退出，不持续累积。

## 每个场景的空间与状态

主 Skill 的“先排完整状态，再写动画”在源码中按以下方式落实，用布局结构预防遮挡：

- 每个场景有自己的根容器、局部布局空间和显式状态。先安排视觉主体、必要文字与封装字幕的位置，再安排入场、运动和退出。按父级与自身平移、缩放后的屏幕位置安排空间；主体附带的标签、底框、完整文字、引线和强调框都计入整体占用及运动范围，不能仅按物体锚点、圆点或文字基线判断是否相撞。字幕区域沿用正式封装，不自行重建。
- 首次编写 HTML/CSS/SVG 时，按内容选择整屏聚焦、分区或局部特写的结构，再确定容器宽度、布局关系与坐标；文字和主体各有可读区域，不默认套用左文右图，也不把说明塞进主体剩余的窄缝。固定宽度可以使用，但要适合本场景；结构不合适就改容器或重组场景，不能仅靠提高层级、缩字、变淡或隐藏仍需阅读的内容掩盖冲突。
- 转场从起点到终点都要为同时可见、仍需阅读的对象留出空间。新标题或标签进入前，其阅读区域必须已被旧主体让出；若旧主体仍会穿过该区域，调整运动路径、入场时点或局部遮罩。不同区域的动作仍可重叠接力，不要求全部串行；不能只看转场终点无重叠，就让新旧内容提前交叉覆盖。
- 对象跨场景延续时，明确下一状态的位置、尺度与层级变化，让其适应新的主体关系；场景容器只带走本场景应退出的内容，延续对象置于可独立控制的层。不再需要的旧对象连同其标签、强调框及连接线正常退场，避免残留。
- 删除或替换布局容器时，同步清理对应 CSS，并移除或改绑 GSAP 的 `set/to/fromTo`、组选择器及后续显隐补间，避免旧结构被再次显示。仍需讲解的信息转入新结构，按原口播语义时点呈现。
- SVG 连线先按节点的实际边界和连接侧确定起点、终点与分支；HTML 节点与 SVG 混排时，将节点边界换算到连线所在的局部坐标，计入 `viewBox` 与父级变换。端点对准对应节点并留合适间隙，路径绕开文字和主体有效区域；节点相对位置或尺寸变化时同步更新路径，整体移动时可共用运动父组。需被主体遮挡的线先绘制，主体和节点后绘制，不靠 `z-index` 掩盖错误路径。
- CSS 选择器和定位限制在所属场景根容器内，不让通用样式或全局绝对定位影响其他场景。SVG 的对象、渐变、遮罩、裁切和箭头等 ID 在同一文档内唯一，可用片段/场景前缀区分；动画选择器指向所属的实际元素，避免同名目标串场。
- 独立渲染片段不共享 DOM 或动画状态。确需跨段连续时，在前后段源码中明确同一对象的身份及边界构图，并各自写清初态；不依赖上一段运行后留下的位置或显隐状态，不新增交接字段。
- 具象对象可以丰富，复杂度由解释需要决定。拥挤时先重组空间、调整整组比例或展示顺序，保留必要关系和可读性；不以减少所有视觉元素、统一卡片模板或全画面裁切逃避布局问题。

## 状态与三种时间

先明确主体、将要发生的变化和必须保留的依据，再选择移动、重排、尺度变化、遮罩、高亮、描线或切换。不要求每个对象都有入场效果；需要持续辨认时复用其身份，进入新问题无需保留所有元素。

- **语义时点**：口播何时提到对象、关系或结论，决定何时展示。
- **动作耗时**：依据距离、尺度与信息重要程度安排。
- **阅读停留**：为文字、数据与新关系保留稳定辨认时间。

按完整语义组织状态，不按每条 SRT 换屏。句级字幕不冒充逐词时间。选段时间原点只换算一次：完整音轨时间减 `renderStart` 得到片内时间；精确裁取、从零开始的本段音频直接用其 `currentTime`。

## 外层定位，内层运动

布局坐标与动画变换放在不同元素。SVG 原生平移若与 GSAP 的 `x/y` 写在同一对象上，`x:0,y:0` 可能将原定位覆盖，造成对象跳到错误区域。例如：

```html
<g transform="translate(720 280)">
  <g id="moving-object"><!-- 自由绘制的对象 --></g>
</g>
```

```js
tl.set('#moving-object', { x: 0, y: 0 }, 0);
tl.to('#moving-object', { x: 180, duration: 0.8 }, 2);
```

外层保留定位，内层只承担相对运动；CSS 布局与 GSAP 变换也按此分层。不要在带原生 `translate` 的同一 `<g>` 上再用 `x:0,y:0` 作为通用归零。外层布局原点改变时，同步换算受影响补间的起止位移，保持需要延续的对象在屏幕上的位置连续，不能只改静态 CSS 而保留失配的动画坐标。

标题、说明和图形依据当前场景的可用空间、完整运动范围和层级安排。确需让图形留在局部区域时，给该图区使用 `clipPath` 或嵌套 SVG；标题可独立成层。不将全画面统一裁切，不强制每页相同坐标或模板。保留精细 SVG、自由路径、重组与连续运动能力。

## 单一暂停时间轴

[C 示例源码](../assets/examples/c-object-continuity.js) 展示现有方法：同步建立一条暂停时间轴，以 `set/to/fromTo` 写清初态、终态和变换原点，外部通过 `renderAtTime(seconds)` 定位，不由画面自行计时。首次零秒与回零曾出现差异，封装保留先定位末尾再回零的初始化；它不代替消除同属性零秒重复赋值。

同一对象的同一属性不要同时被整组初态与首场景写入，整组隐藏应排除单独显示的首场景。SVG `<symbol>/<use>` 中的填充、描边与 `fill:none` 在实例内明确生效，不只依赖外部祖先选择器。

相同时间重复或异序定位应得到相同状态，不依赖随机、网络、墙钟或顺序播放。示例播放器的时钟只模拟外部时间，正式制作由原音轨或已有渲染器驱动；不在本 Skill 中新建导出系统。

## 动作衔接

按用途选缓动：稳定状态间重排可平滑加减速，短强调可更快，均速描线可用线性进度。持续前进的对象避免每段无意停到零速；重叠动作保持主次，不无意重写同属性。单纯加长缓动、加弹跳或淡入不能修复两个布局状态的冲突。

动作短促、准确、流畅，完成后为新的重点留下稳定阅读时间，不用慢速漂移填满口播。因果明确的入场、退出、主体移动、数字变化与镜头交接可在同一时间轴中合理重叠、接力，不必等每个动作完全结束再启动下一个；同一对象同一属性的控制要有明确交接，避免竞争。沿用真实口播时点，不提前揭示结论；主要镜头在关键文字或关系进入阅读时稳定，必要的局部过程可以继续。

这些是创作判断，不是额外逐段观看门槛。正式制作最终由程序检查技术项目；仅在实际定位故障时定点复核。用户明确要求视觉评审时再依对应参考查看运动与节奏。60fps 是项目默认输出，不能据此承诺所有视频的观感。
