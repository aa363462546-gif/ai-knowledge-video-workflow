# 用户明确要求时的视觉评审

仅当用户明确要求视觉评审时读取并执行本文件。普通正式制作不进入此环节，不做逐段 AI 审美、截图自查、视觉评分、评审 Agent 或自动主观返工；最终基础程序检查见正式制作流程。

## 评审范围由当前请求决定

| 观察 | 关注的问题 |
| --- | --- |
| 内容 | 是否忠实保留口播原意、必要条件和真实依据？ |
| 理解 | 主体是否明确，比较依据是否便于对照，画面是否帮助理解？ |
| 设计 | 层级、比例、间距、留白与必要文字是否适合观看？ |
| 动态 | 对象是否持续可辨、焦点交接是否清楚、动作与停留是否合适？ |

按用户指定的片段、静态图或问题查看，不自动扩成全片、多轮或新的评审系统。用户要求动态节奏与同步评审时，才实际连续观看相应音画；静态截图或技术通过不能替代这一证据。没有观看的部分明确写为未验证。

需要读图时遵守图片上下文隔离：全新短命线程一次最多一图，只返回路径、可读性、版式问题和建议等文字，图片和编码不回传主实现线程。

## 具体证据与停止

使用“哪个位置、出现什么、怎样影响观看”的说明，不以 AI 自评分宣布优秀或验收。结构、解码与资源检查只证明对应技术情况；用户认可某个动作也不等于认可整片。

评审结果不自动授权主观返工。用户明确要求修改时，只处理已确认范围并做对应复核，保留已有输出与认可部分；完成本次请求即交付，不追加评分、门禁或长期自动审核。
