# 视觉资产质量与轻量动作

正式口播创作在选择资产和编码前读取。沿用 [Design System](../../../design-system-v1/DESIGN-SYSTEM.md) 的字体、配色角色、边界和基础美术规范；本文件补充对象造型与动作做法，不另立画风。

## 按对象与所需动作选择资产

- 数学图形、图表、标尺、箭头、关系节点，以及轮廓简单的小物件可直接绘制 SVG，保证准确、干净、可控。
- 人物、轮船、汽车、店铺、建筑、机械等复杂具象对象，优先选用造型成熟、精致的插画、SVG 素材、分层图片或合适的 3D 资产；能完成精细 SVG 时也可自行绘制。按最终造型与动作需要选择媒介，不强制使用 AI 图片，也不把复杂对象默认交给粗糙几何拼接。
- 重要主体优先保证合理比例、完整结构和可辨识身份；远景、配角可减少细节，但轮廓和结构仍应成立。同一作品统一造型语言、透视、线宽与明暗，资产与既有 Design System 协调。
- 资产的表达维度遵循 [主 Skill](../SKILL.md) 的“自动选择 2D、2.5D 或 3D”章节，按主体造型、运动与镜头需要选择媒介，不预先限定为 SVG 或三维。

## 造型与连接在制作时完成

- 不使用火柴人、潦草体块拼图、明显毛刺、悬空部件或错误线条连接作为正式主体。人物用完整体块及必要的服装、手脚细节交代身份；轮船、车辆、店铺和机械保留可辨识的主体结构与关键部件，不能靠标题解释难以认出的形状。
- 手与道具尺度协调，持物、指向、接触位置合理；先解决比例和结构，再添加装饰细节。
- SVG 应闭合的轮廓闭合、接缝对齐，按观看尺度选择描边和接角，避免尖刺与突出线头。后方线条由前方实体正确遮挡，活动部件保留必要的连接重叠，避免露缝、断肩或线条穿过主体。

## 只拆动作需要的层

- 将背景、主体、必要活动部件和手持物按动作需要分组；布局定位在外层，GSAP 运动在内层。需要跨场景延续的主体独立于会退场的环境，保留身份与交接能力，不把整张插画逐页淡入淡出当作默认动画。
- 简单动作采用整体移动、少量部件转动、关键姿态切换或少量透明图层配合 GSAP。姿态之间保持人物轮廓、服装、比例与持物关系一致。
- 动作超出当前资产能力时，选择合适的关键姿态或简化动作；不默认建立复杂人物骨骼、关节和手指绑定，不为短暂动作长时间反复修肩、肘、腕。投入集中在可见且有解释作用的部分，以表达准确、自然可接受为止。

上述要求由现有创作过程直接落实；动态导演与空间安排共用 [动态参考](motion-and-time.md)，不增加逐帧检查、审核 Agent、评分器或多轮主观返工。
