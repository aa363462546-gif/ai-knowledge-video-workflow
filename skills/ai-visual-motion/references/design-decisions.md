# 设计判断：先知道观众要看懂什么

需要确定主体、试排或比较表达形式时读本文件。视觉语言沿用 [项目 Design System](../../../design-system-v1/DESIGN-SYSTEM.md)，无需为每次创作另写一套策划表；几句判断和实际试排就可以推进。

## 从真实内容形成视觉方向

先看受众和媒介：是需要快速辨认的手机讲解，还是允许停留阅读的大屏演示？内容偏概念、数据、软件操作还是观点论证？在统一字体、配色与质感下，据此决定主体比例、对比强弱、图形表达和密度。

将本片的选择写成简短说明：现有字体层级各承担什么角色，颜色如何区分主次或对象，形状是否编码了关系，哪些部分应当安静。直接使用设计系统的本地变量与字体，不在每个场景重新确定品牌风格。

风格一致主要体现为语义与层级稳定：同一对象不随意换身份色，同一级文字保持可识别的角色，线条或图标使用相近语言。它不要求每幕同一种容器、对称方式或元素数量。

## 确定主体

用一句话描述“观众看完这一状态，应能看出____”。把真正完成这个任务的信息放到第一视觉层：比较的依据、变化的对象、可核实的数值或需要理解的关键句。

标题通常提供导航，Logo通常提供身份；当主题恰好是名称或品牌时，它们也可以成为主体。不要为了显得专业，机械地压小所有标题或放大所有图形。

信息很少但主体仍显得弱小时，尝试放大整组、改变分区和对比。信息太多时，先判断哪些内容需要同时比较，哪些可以随口播逐步展开；删重复、分状态，再讨论字号。没有必要用装饰填补空白。

## 选择表达，而不是寻找关键词模板

| 观众任务 | 候选及取舍问题 |
| --- | --- |
| 记住少量项目或顺序 | 短句、列表、编号胶囊、分组排版。编号是否真的需要强调先后？没有依赖时，箭头是否增加了理解收益？ |
| 追踪过程 | 状态接替、实际对象改变、流程图。观众需要看分支和依赖，还是只需知道先后？ |
| 比较两方 | 共享对应行、同尺度图形、并置摘录、主次布局。需要逐项核对，还是当前只解释一个差异？ |
| 解释机制或关系 | 对象内部变化、输入输出、包含或连线。材料是否支持因果、归属或流向，还是只说明同时存在？ |
| 读取数量 | 直接数字、表格或适当图表。是否有真实值、单位与共同尺度？精确读取与趋势辨认哪个更重要？ |
| 理解定义或结论 | 清楚的文字、必要例子或局部高亮。增加图形会帮助理解，还是要求观众再解释一层隐喻？ |

表格是提问方式，不是路由表。一个任务可能有多种合理表达，同一种图形也可能服务不同任务。只有候选确有差异时，比较其解释收益、读图成本、内容忠实程度与制作代价。

简单与复杂都不是质量指标。三个纯顺序项目用纵向编号胶囊可以清楚、规整；若要讲分支或并行，继续套三个胶囊就可能隐藏关系。卡片、阶梯和流程图同样按用途判断。

## 用真实内容建立排版

1. 从最难处理的必要内容试排：最长术语、数值单位、解释文本或真实截图，而不是短占位词。
2. 先确定共同边界、主要分区与阅读入口，再安排基线、行距及组内/组间距离；无需预先指定固定栏数。
3. 字号、字重、位置与间距共同建立层级。正文要能读，条件要能找到，标题不要挤占解释空间；不要求所有层级都很大。
4. 直接比较的项目尽量共享行或尺度。文字长短不同可以保留差异，不能为追求表面齐整而漏掉关键限定。
5. 在实际播放器显示大小下看，而不只看1920像素原图。确认重点可辨、中文断行合理、同时展示的信息来得及读。

对称适合需要公平并置的比较；非对称适合有明确主次或当前焦点。打破对称应能指出信息目的，不只是制造变化。

## 清理辅助文字

逐条问：这行字是在解释、限定、标识，还是重复旁边已经清楚的信息？

- 必要的单位、条件、来源标识和消除歧义的标签，应贴近所解释对象并保持可读。
- 重复口播的整段文字、重复标题、没有解释作用的标签，可以删减；字幕是否保留遵从用户需求，不能与主画面冗余混为一谈。
- 制作备注、内部运行状态与非讲解主题的技术说明留在创作文件；留白不需要用灰色小字填满。
- 提高可读性可以通过减少数量、重新分组、提高对比和增加停留实现，不只靠统一放大。

## 方法来源与适用边界

- [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)：借鉴基于真实主题确定方向、先形成简短设计意图再实现、克制装饰；网页交互和首屏规则不直接照搬为视频规则。
- [IBM 布局语言](https://www.ibm.com/design/language/layout/overview/)：参考层级、比例、对比与留白的共同作用，不照搬其品牌外观。
- [FT Visual Vocabulary](https://github.com/Financial-Times/chart-doctor/blob/main/visual-vocabulary/README.md)：按需要表达的信息关系认识图形候选，不按词语自动选图。

以上是判断依据，不是成片审美已经获得保证。
